Status do sistema
Como funciona

1. Adicione um bot colando o token do @BotFather. Sem URL pública ele funciona em polling (o próprio aparelho pergunta as mensagens ao Telegram).

2. Monte o fluxo. Cada nó é uma tela: texto, mídias, botões e o destino de cada botão. O nó inicial é onde o /start cai.

3. Pix: um nó com valor > 0 trava o cliente até o pagamento ser aprovado e então segue para o “próximo nó”.

4. Inatividade: se o cliente demora, vai para o nó de retorno daquele nó. O nó de resgate recebe quem ficou “sem caminho” (fim de linha ou Pix travado).

5. Grupos: cadastre um grupo onde o bot é admin e envie um convite de uso único ao final de um nó.

Dicas rápidas

• O botão ⚙️ mostra o status (modo, polling, pagamentos, avisos).

• Use o nó de resgate com botões para “puxar” o cliente de volta ao fluxo.

• Exporte o fluxo (⬇) para guardar um backup em JSON.

• Se o bot parar de responder no celular, abra o Termux e rode bash scripts/termux/start.sh.
